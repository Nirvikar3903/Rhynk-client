# Rhynk Client

Frontend-only repo for Rhynk, a chat + social-music app ("Every Chat Has a
Rhythm"). Full project rules live in `.claude/rules/` and are mirrored
(identical content) in `.antigravity/rules/` for Antigravity — keep both in
sync when either changes.

Recurring scaffolding tasks (new component, new feature module, new Redux
slice, etc.) have step-by-step playbooks in `.claude/workflows/` (mirrored in
`.antigravity/workflows/`) — read the relevant one before starting that kind
of task: `create-component`, `create-hook`, `create-page`, `create-form`,
`create-api-service`, `create-redux-slice`, `create-parser`,
`create-mui-component`, `create-feature-module`, `setup-encryption`,
`figma-integration`.
